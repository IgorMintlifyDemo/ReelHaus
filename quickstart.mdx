This guide walks you through searching for a movie and fetching its details.

<Steps>
  <Step title="Get your API key">
    Create an API key from your Reelhaus account. See [Authentication](/authentication) for details.
  </Step>
  <Step title="Search for a movie">
    Send a `GET` request to `/movies` with a `query` parameter.

    <CodeGroup>

    ```bash cURL
    curl "https://api.reelhaus.example/v1/movies?query=heat" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://api.reelhaus.example/v1/movies?query=heat",
      { headers: { Authorization: "Bearer YOUR_API_KEY" } }
    );
    const { data } = await response.json();
    ```

    ```python Python
    import requests
    
    response = requests.get(
        "https://api.reelhaus.example/v1/movies",
        params={"query": "heat"},
        headers={"Authorization": "Bearer YOUR_API_KEY"},
    )
    data = response.json()["data"]
    ```

    </CodeGroup>
  </Step>
  <Step title="Read the response">
    You get back a list of matching movies and pagination details.

    ```json
    {
      "data": [
        {
          "id": "mov_3xq9z",
          "title": "Heat",
          "release_year": 1995,
          "genres": ["action", "thriller"],
          "average_rating": 8.3
        }
      ],
      "pagination": { "page": 1, "per_page": 20, "total_results": 1, "total_pages": 1 }
    }
    ```
  </Step>
  <Step title="Get the full details">
    Use the movie's `id` to fetch everything about it, including synopsis, runtime, and box office.

    ```bash
    curl "https://api.reelhaus.example/v1/movies/mov_3xq9z" \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Step>
</Steps>
