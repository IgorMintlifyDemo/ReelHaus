Do critics and audiences agree with the box office? The `GET /rankings` endpoint answers that in a single request. It returns two ranked lists for the same films, one by average review rating and one by worldwide gross, and tells you where each film lands in the other list.

## Get the rankings

```bash
curl "https://api.reelhaus.example/v1/rankings?year=2008&limit=5" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

| Parameter | Default | Description |
| --- | --- | --- |
| `year` | All years | Only rank films released in this year. |
| `genre` | All genres | Only rank films in this genre. |
| `min_reviews` | `50` | Leave out films with fewer reviews, so a handful of ratings can't top the list. |
| `limit` | `10` | Films per list, up to 50. |

## Reading the response

The response has two arrays, `by_reviews` and `by_box_office`. Each entry includes:

- `rank`: the film's position in that list
- `movie`: the film's ID, title, and release year
- `average_rating` and `worldwide_gross_usd`: both scores, whichever list it's in
- `rank_in_other_list`: where the film places in the other ranking, or `null` if it doesn't qualify there

<Tip>
To find the biggest disagreements, sort entries by the difference between `rank` and `rank_in_other_list`.
</Tip>
